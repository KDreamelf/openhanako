# PH01 密钥管理

本文记录主根密钥、主控证书和吊销策略。

## 结构

1. 核心根密钥对
   - 开发阶段生成
   - 私钥首次使用后及时封存
   - 根公钥内置到子体客户端

2. 主控证书
   - 由根私钥签发
   - 作为主要工作的证书
   - 用于认证中心与客户端的主信任链

3. 吊销列表
   - 主控证书的额外信息区域预留吊销证书指纹列表
   - 如果主控证书私钥泄露，启封根私钥重新签发主控证书
   - 新主控证书携带旧证书指纹到吊销列表

## 约束

- 根私钥不参与日常业务通信
- 业务流只使用主控证书或其下发的工作证书
- 证书泄露优先走吊销和重签发，不靠“默默继续使用”

## 开发证书

开发环境可用 `scripts/generate-ph01-mtls-devcerts.go` 生成：

- 根 CA
- 认证中心证书
- 网关证书

生成结果默认写入 `dev-certs/ph01-mtls/`，不建议提交仓库。
