### SSE 流式解析要点

```dart
Stream<String> sseDataLines(Response<ResponseBody> resp) async* {
  final stream = resp.data!.stream;
  final buffer = StringBuffer();
  await for (final chunk in stream) {
    buffer.write(utf8.decode(chunk, allowMalformed: true));
    while (true) {
      final str = buffer.toString();
      final idx = str.indexOf('\n');
      if (idx < 0) break;
      final line = str.substring(0, idx);
      buffer.clear();
      buffer.write(str.substring(idx + 1));
      if (line.startsWith('data: ')) yield line.substring(6);
    }
  }
}
```

OpenAI 与 Anthropic 都用 SSE 但 event/data 字段语义不同，要分别实现解析器。

## 3.4 Skill 系统：外部进程模式

### 现状
Electron 端 skill 大概率是 JS 文件 + Node.js eval（具体实现需查 `core/skill-manager.js` 与 `skills2set/`）。

### Dart 端方案
每个 skill 是一个**独立可执行文件**（任意语言写），通过 stdin/stdout 通信。

**协议**：
- skill 进程从 stdin 读取一行 JSON：`{"input": ..., "context": {...}}`
- skill 进程向 stdout 写一行 JSON：`{"output": ..., "metadata": {...}}`
- 出错则 exit code != 0 + stderr 写错误信息
- 行结束符强制 LF（防 N-BUG-4 跨平台差异）

**SkillRunner 实现**：

```dart
class SkillRunner {
  Future<SkillResult> run(SkillSpec spec, Map<String, dynamic> input) async {
    final proc = await Process.start(
      spec.executable,
      spec.args,
      environment: {...Platform.environment, ...spec.env},
      workingDirectory: spec.workdir,
      runInShell: false,
    );
    proc.stdin.writeln(jsonEncode({'input': input, 'context': await _ctx()}));
    await proc.stdin.close();

    final stdoutFut = proc.stdout.transform(utf8.decoder).join();
    final stderrFut = proc.stderr.transform(utf8.decoder).join();
    final exit = await proc.exitCode;

    if (exit != 0) {
      return SkillResult.error(await stderrFut, exit);
    }
    return SkillResult.fromJson(jsonDecode(await stdoutFut));
  }
}
```

**Node.js skill 兼容（迁移期）**：
- skills2set 中现有 JS skill 可通过 `node skill.js` 调用（用户系统装了 node）
- 提供 `migrate-skill.dart` 脚本协助转换
- 兼容 1-2 个版本后强制迁移

### 高斯衰减算法

参考 `lib/memory/memory-ticker.js` 与 `memory-compile.js`：

```dart
double computeDecay(Fact fact, DateTime now) {
  final ageMs = now.millisecondsSinceEpoch - fact.lastAccessedAt;
  final ageHours = ageMs / (1000 * 3600);
  final sigma = _sigmaFor(fact.importance);
  return math.exp(-(ageHours * ageHours) / (2 * sigma * sigma));
}
```

后台 isolate 跑 ticker（每日定时更新 `decayCoefficient` 字段），UI 主 isolate 只读。

### 流式消息渲染要点

```dart
class StreamingMessageWidget extends ConsumerWidget {
  final String messageId;

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final msg = ref.watch(streamingMessageProvider(messageId));
    return RepaintBoundary(
      child: Column(
        children: [
          if (msg.thinking.isNotEmpty) ThinkingBlock(text: msg.thinking),
          if (msg.text.isNotEmpty) MarkdownBody(data: msg.text),

      ),
    );
  }
}
```
