# 02 · 多窗口实现方案

## 2.1 当前 8 个窗口清单（来自 `desktop/main.cjs`）

| # | 名称 | 触发时机 | 是否独立必要 |
|---|------|---------|-------------|
| 1 | Splash | 启动时（等 server） | 可合并到主窗口 |
| 2 | Main | 启动完成后 | **必须** |
| 3 | Onboarding | 首次启动 | 可改为路由 / Modal |
| 4 | Settings | 用户打开设置 | **保留独立**（用户常并排） |
| 5 | DevTools | 调试模式 | Flutter Inspector 替代 |
| 6 | Skill Viewer | 查看技能 | 可改为 Modal |
| 7 | Browser Viewer | 内嵌浏览器 | **保留独立**（内容窗口） |
| 8 | Editor Window | 代码编辑器 | **保留独立**（与聊天并排） |

### 推荐窗口收敛策略

```
独立窗口 (4 个) → desktop_multi_window 创建：
  - Main         主聊天
  - Settings     设置面板
  - Browser      浏览器视图
  - Editor       代码编辑器

主窗口内 Modal / Route：
  - Splash       → 主窗口启动屏（flutter_native_splash + Lottie）
  - Onboarding   → 主窗口路由 /onboarding
  - Skill Viewer → showDialog(...) 或 Drawer
  - DevTools     → debug 模式自动 Flutter Inspector
```

**为什么收敛？** Flutter 子窗口是独立 Engine（每窗口约 30-50MB 内存），8 个窗口体验上多余的还会让冷启动变慢。

## 2.2 插件对比：`desktop_multi_window` vs `multi_window_native`

### 详细维度

| 维度 | desktop_multi_window | multi_window_native |
|------|----------------------|---------------------|
| 维护方 | leanflutter（与 window_manager / tray_manager / auto_updater 同家族） | 个人 / 小团队 |
| 上次更新 | 2025-10（活跃） | 1.0.3，频率较低 |
| 平台 | Win / macOS / Linux | Win / macOS / Linux |
| 子窗口 Engine | 每窗口独立 Flutter Engine | 同左 |
| API 风格 | `DesktopMultiWindow.createWindow(args)` 返回 `WindowController` | `multi.createWindow([...])` 字符串数组 |
| IPC API | `invokeMethod(targetId, method, args)` + `setMethodHandler` | 类似但文档稀疏 |
| 黑屏 / 初始化 | 入口判断 args 即可 | **要求子窗口主动通知 native UI ready** |
| 与 window_manager / tray_manager 协同 | 官方推荐 | 不明确 |
| 社区生态 | star 多，issue 响应快 | 较少 |
| 学习曲线 | 平缓 | 文档少，要看源码 |

### 推荐：`desktop_multi_window`

**理由**：
1. 与 `tray_manager` / `auto_updater` 同一家族，少踩坑
2. 黑屏问题不需要额外手动处理
3. 文档/示例丰富，社区 issue 多 —— 这点对长期维护至关重要

`multi_window_native` 的优势在「更接近 native」，但本项目所有窗口都是 Flutter UI，没有原生 view 嵌入需求，这个优势不构成选型动力。

### 备选：`window_manager_plus`

如果 `desktop_multi_window` 在某个平台出严重 bug，可以备选 `window_manager_plus`（也支持多窗口 + 互通信，API 略不同）。但首选不变。

## 2.3 入口文件设计（main.dart）

```dart
import 'dart:convert';
import 'package:flutter/material.dart';
import 'package:flutter/services.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:desktop_multi_window/desktop_multi_window.dart';

void main(List<String> args) async {
  WidgetsFlutterBinding.ensureInitialized();

  // 子窗口入口：args = ['multi_window', '<windowId>', '<jsonArgs>']
  if (args.firstOrNull == 'multi_window') {
    DartPluginRegistrant.ensureInitialized();   // 防 N-BUG-9（见 04 章节）
    final windowId = int.parse(args[1]);
    final raw = args.length >= 3 ? args[2] : '{}';
    final wargs = raw.isEmpty
        ? <String, dynamic>{}
        : jsonDecode(raw) as Map<String, dynamic>;
    final controller = WindowController.fromWindowId(windowId);
    final route = wargs['route'] as String? ?? 'main';

    runApp(SubWindowApp(controller: controller, route: route, args: wargs));
    return;
  }

  // 主窗口入口：直接初始化业务核心（无子进程，无 HTTP）
  final engine = await HanaEngine.initialize();
  runApp(ProviderScope(
    overrides: [engineProvider.overrideWithValue(engine)],
    child: const MainApp(),
  ));
}
```

## 2.4 创建子窗口示例

```dart
Future<int> openSettingsWindow(WidgetRef ref) async {
  final win = await DesktopMultiWindow.createWindow(jsonEncode({
    'route': 'settings',
    'theme': ref.read(themeProvider).name,
    // 不传 serverPort —— Engine 是同进程内单例，子窗口通过 IPC 调用主窗口业务
  }));
  win
    ..setFrame(const Offset(120, 120) & const Size(960, 720))
    ..setTitle('设置 · Hanako')
    ..center()
    ..show();
  return win.windowId;
}

Future<int> openEditorWindow({required String filePath}) async { /* ... */ }
Future<int> openBrowserWindow({required String url}) async { /* ... */ }
```

> **关键差异**：每个子窗口是独立 Flutter Engine（独立 Isolate），**不能直接共享 lib/core/ 单例**。
> 业务调用必须通过 IPC（method channel）走主窗口的 Engine —— **主窗口扮演业务核心 host**。
> UI 状态（主题、当前 tab）各窗口私有；业务状态（session、模型）通过 IPC 同步。

## 2.5 跨窗口 IPC 设计

### 现状（Electron）
```
Renderer → ipcRenderer.invoke('foo', payload) → Main → ipcMain.handle('foo', ...)
Renderer → fetch('http://localhost:port/api/...') → server
```

### Dart 等价

| 通信场景 | 方案 |
|---------|------|
| 子窗口 → 主窗口（业务调用） | `DesktopMultiWindow.invokeMethod(0, 'business.invoke', {api, payload})` |
| 主窗口 → 子窗口（推送） | `DesktopMultiWindow.invokeMethod(targetId, 'method', args)` |
| 主窗口业务核心 ↔ 数据 | **直接 Dart 函数调用 lib/core/**（同进程单例） |
| 业务事件 broadcast | 主窗口订阅 Engine event stream，向所有子窗口 invokeMethod |

### IPC method registry（建议）

| method 名 | 方向 | 用途 |
|----------|------|------|
| `bring_to_front` | any → main | 子窗口请求主窗口前置 |
| `business.invoke` | sub → main | **通用业务调用**，args = `{api: 'session.list', payload: {...}}` |
| `notify_session_changed` | main → all | session 切换 |
| `notify_theme_changed` | main → all | 主题切换 |
| `notify_locale_changed` | main → all | 语言切换 |
| `notify_engine_event` | main → all | streaming / model fallback / 错误 |
| `request_close_all_subs` | main → all subs | 主窗口关闭前广播 |
| `editor_save_done` | editor → main | 编辑器保存完毕 |
| `editor_request_open` | main → editor | 主窗口请求编辑器打开文件 |

### 业务调用代码示例

```dart
// 子窗口（如 Settings）调主窗口业务
class SubWindowEngineClient {
  static Future<List<ModelInfo>> fetchModels() async {
    final result = await DesktopMultiWindow.invokeMethod(0, 'business.invoke', {
      'api': 'model.list',
      'payload': <String, dynamic>{},
    });
    return (result as List)
        .map((j) => ModelInfo.fromJson(j as Map<String, dynamic>))
        .toList();
  }
}

// 主窗口统一处理
DesktopMultiWindow.setMethodHandler((call, fromWindowId) async {
  switch (call.method) {
    case 'business.invoke':
      final args = call.arguments as Map;
      final api = args['api'] as String;
      final payload = (args['payload'] as Map).cast<String, dynamic>();
      return await businessRouter.dispatch(api, payload);
    case 'bring_to_front':
      await windowManager.show();
      await windowManager.focus();
      return null;
    case 'editor_save_done':
      ref.read(editorEventBusProvider).emit(EditorSavedEvent(call.arguments));
      return null;
    default:
      throw MissingPluginException('Unknown method: ${call.method}');
  }
});
```

### 业务事件广播

```dart
// 主窗口启动后订阅 Engine 事件流，广播给所有子窗口
final subs = engine.events.listen((event) {
  for (final win in DesktopMultiWindow.getAllSubWindowIds()) {
    DesktopMultiWindow.invokeMethod(win, 'notify_engine_event', event.toJson());
  }
});
```

## 2.7 单实例锁

不再有 server 可借力（业务在主进程内），需要纯客户端实现：

```yaml
dependencies:
  windows_single_instance: ^1.1.0    # Win 专用
  # macOS/Linux 用 lock file + flock 自写
```

```dart
// Windows: named mutex
// macOS/Linux: ~/.hanako/.lock + flock + Unix domain socket
final isFirst = await SingleInstanceLock.tryAcquire();
if (!isFirst) {
  // 通过 named pipe（Win）或 unix socket（mac/Linux）通知已运行实例
  await SingleInstanceLock.notifyExisting(args);
  exit(0);
}
```

注册回调让已运行实例响应：

```dart
SingleInstanceLock.onSecondInstance((args) async {
  await windowManager.show();
  await windowManager.focus();
  // 如 args 含文件路径，转发到 editor 窗口
});
```

## 2.8 关键陷阱清单

| # | 陷阱 | 解决 |
|---|------|------|
| 1 | 子窗口插件未注册（method channel not found） | 子窗口 main 第一行调 `DartPluginRegistrant.ensureInitialized()` |
| 2 | 高 DPI 下子窗口位置偏移 | 用逻辑像素而非物理像素；测试 100/125/150% 缩放 |
| 3 | 关闭主窗口子窗口未跟随退出 | 主窗口 `onClose` 广播 `request_close_all_subs`，等待全部 ack 后再 destroy |
| 4 | 子窗口与主窗口主题不同步 | 主题变化时广播 `notify_theme_changed` |
| 5 | macOS 子窗口在 dock 显示重复图标 | 给非主窗口设 `setSkipTaskbar(true)` |
| 6 | 子窗口要直接读 lib/core/ 单例 | **禁止**——必须通过 IPC `business.invoke` |
| 7 | 主窗口处理 IPC 时阻塞 streaming | businessRouter 用 isolate 执行重操作；IPC handler 立即返回 |
| 8 | streaming 事件下发到所有子窗口造成卡顿 | 只广播给订阅过的窗口；用 channel filter |

## 2.9 子窗口业务能力清单

每个子窗口可以通过 `business.invoke` 触发的核心 API（白名单）：

| API | Settings | Editor | Browser |
|-----|---------|--------|---------|
| `model.list` | ✅ | - | - |
| `model.set_active` | ✅ | - | - |
| `provider.register` / `unregister` | ✅ | - | - |
| `oauth.start` / `poll` / `cancel` | ✅ | - | - |
| `config.read` / `update` | ✅ | - | - |
| `session.list` | ✅ | ✅ | - |
| `skill.install` / `remove` | ✅ | - | - |
| `editor.read_file` / `write_file` | - | ✅ | - |
| `browser.navigate` | - | - | ✅ |

主窗口的 `businessRouter` 应该对每个子窗口做能力白名单校验，防止任意子窗口调任意业务。
