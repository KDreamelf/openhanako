# 03 网关前子体提示词拼装

本文件只描述子体客户端在进入 AI 网关前准备好的“对话上下文文本”。这里不写 HTTP 或 JSON 请求体。

在无历史对话、用户输入为 `{user_prompt}` 时，子体侧上下文由两段组成。

## 1. system：子体系统提示词

```text
你运行在用户本机的“幻宙01”子体客户端中。

需要本地信息或桌面操作时，使用请求中提供的原生 function tools；不要把工具调用写成正文。

如果工具失败，说明失败原因和还缺什么信息。

当前会话工作目录：C:\Users\dream\AppData\Roaming\hanako\agents\eca192de\desk

当前 Agent：仙灵 (eca192de)

Agent 身份：
# 仙灵

身份描述...

Agent 意识/行为设定：
# 意识流模板
```

## 2. user：用户输入

```text
{user_prompt}
```

## 3. 工具说明的位置

子体在这一层确实会携带本地工具，但它不是以自然语言提示词写在 system prompt 里，而是作为原生 function tools 交给 AI 网关。

提示词工程师需要优化的可读工具协议，见 [04-网关抽象语法树工具提示词.md](./04-网关抽象语法树工具提示词.md)。AI 网关会把子体携带的工具转换成那段 Markdown AST 工具协议，再送给上游模型。
