## 上下文流向

1. 子体运行时从 session JSONL 读取历史消息。
2. 子体把当前 system prompt 插到消息首位。
3. 子体把本地工具和 Windows 桌面工具作为 OpenAI function tools 放进请求。
4. 子体通过 `/api/v1/llm/chat` 发送加密信封；提示词层面的拼装见 `03`。
5. AI 网关若启用 Markdown AST 工具调用，会额外插入一个工具协议 system prompt。
6. 网关把 assistant/tool 历史里的原生 tool calls 转成 Markdown AST 块，并清空原生 `tools`/`tool_choice`。
