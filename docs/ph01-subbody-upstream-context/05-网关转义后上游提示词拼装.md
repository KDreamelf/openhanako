本文件只写 AI 网关转义后，上游模型实际看到的提示词顺序。不写 JSON 请求体。

无历史对话、用户输入为 `{user_prompt}` 时，上游模型看到的顺序如下。

这段由 AI 网关插入，完整正文见 [04-网关抽象语法树工具提示词.md](./04-网关抽象语法树工具提示词.md)。

## 2. system：子体系统提示词

内容与 [01-子体系统提示词.md](./01-子体系统提示词.md) 相同。

## 3. user：用户输入

```text
{user_prompt}
```

## 4. 工具返回后的继续上下文

工具调用和工具返回后的完整拼装稿见 [06-单轮无历史上下文流转.md](./06-单轮无历史上下文流转.md)。

那里按顺序写了：

1. 首次进入上游模型的 3 个上下文块。
2. assistant 工具调用块如何进入下一轮。
3. 工具返回块如何作为 user 上下文进入下一轮。
4. 模型如何继续输出或继续调用工具。
