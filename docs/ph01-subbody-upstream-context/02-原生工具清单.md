# 02 原生工具清单

本文件只列提示词工程师需要知道的工具入口，不写 OpenAI function JSON。

当前子体实际注册了 33 个工具：

- 本地工具：28 个
- Windows 桌面工具：5 个

完整的上游可读工具协议，见 [04-网关抽象语法树工具提示词.md](./04-网关抽象语法树工具提示词.md)。

## 本地工具

| 工具 | 用途 |
|---|---|
| `read` | 读取本地文本文件内容。 |
| `write` | 写入本地文本文件。 |
| `edit` | 替换本地文本文件中的指定文本。 |
| `bash` | 在当前工作目录执行 shell 命令。 |
| `grep` | 在目录下搜索文本。 |
| `find` | 按文件名或路径片段查找文件。 |
| `ls` | 列出本地目录内容。 |
| `search_memory` | 搜索当前 Agent 的本地记忆文本。 |
| `web_search` | 搜索互联网；当前 Flutter 客户端需要配置搜索 provider 后才能执行。 |
| `web_fetch` | 抓取指定 http/https URL 并提取文本。 |
| `todo` | 管理当前客户端会话内的待办清单。 |
| `pin_memory` | 写入当前 Agent 的置顶记忆。 |
| `unpin_memory` | 从置顶记忆中移除内容。 |
| `list_pinned_memory` | 列出置顶记忆。 |
| `recall_experience` | 查看当前 Agent 的经验库索引或指定分类。 |
| `record_experience` | 把经验记录到当前 Agent 的经验库。 |
| `experience_search` | 检索 PH01 经验包文件树，只返回经验 ID、文件路径、行号和短片段。 |
| `cron` | 创建和管理定时任务。 |
| `create_artifact` | 创建 HTML、代码或 Markdown 预览内容。 |
| `channel` | 管理频道消息，并可触发多 Agent channel triage。 |
| `ask_agent` | 向另一个 Agent 发起一次同步任务。 |
| `dm` | 给另一个 Agent 发送私信，或配置 DM 自动回复开关。 |
| `message_agent` | 向另一个 Agent 发送消息并等待回复。 |
| `browser` | 控制浏览器打开网页、读取页面标题/文本和查看状态。 |
| `install_skill` | 为当前 Agent 安装 Anthropic Agent Skill。 |
| `notify` | 向用户发送系统通知。 |
| `delegate` | 委派独立子任务给后台 Agent。 |

## Windows 桌面工具

| 工具 | 用途 |
|---|---|
| `windows_capture_region` | 截取 Windows 屏幕局部区域，返回 PNG base64。 |
| `windows_uia_tree` | 读取 Windows UI Automation 控件树。 |
| `windows_uia_invoke` | 对 Windows UIA 元素执行 InvokePattern。 |
| `windows_ocr_recognize` | 使用本地 OCR 模型识别图片文字。 |
| `windows_ui_parse` | 使用本地界面识别模型解析截图中的可交互元素。 |

## 对提示词工程的关键点

- 上游模型最终不会看到 OpenAI function JSON。
- AI 网关会把工具转成 Markdown AST 工具协议。
- 模型调用工具时，应输出 `<----工具调用开始：工具名---->` 块。
- 工具结果会以 `<----工具返回开始：工具名---->` 块进入下一轮上下文。
- `experience_search` 只用于检索路径和短片段；完整读取仍应通过 `read`、`grep`、`ls` 或 `bash`。
