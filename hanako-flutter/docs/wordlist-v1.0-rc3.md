> - 高端食材（佛跳墙/燕窝/鱼翅/鲍鱼/海参）→ 街头快餐（蛋炒饭/酸菜鱼/酸辣汤/炸鸡/披萨）

> - 古文房（印章石/木刻刀）→ 现代文具（铅笔/彩笔）
> - 俗名（蝉→知了、貂鼠→野兔、银锭→银币）
> - 回滚 v1.0-rc2 中过度标准化的词（沙琪玛/豆腐脑/凉粉/玫瑰花茶）
> 
> 标准（v1.0-rc3 后修订）：
> 1. 通俗 / 口语 / 网络流行 / 生活化
> 2. 用户编故事时能立刻形成画面
> 3. 不要追求"标准化"——异形词同义词都可以并存（LLM 解析时映射）
> 4. 偏书面 / 偏雅称 / 偏专业 / 偏古的词都要砍掉
